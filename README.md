# Log Sentinel

A Python-based security log analysis platform designed to simulate Security Operations Center (SOC) workflows.

## Features

• Authentication log parsing

• Failed login detection

• Brute-force attack identification

• Risk-level classification

• CSV incident reporting

## Technologies

• Python

• Regex

• CSV

• GitHub Codespaces

IP Address: 172.16.0.25
Failed Attempts: 4
Risk Level: High
